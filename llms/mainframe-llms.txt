## What Mainframe does and does not publish

- There is NO REST API, NO OpenAPI or Swagger document, and NO developer portal on any
  Mainframe-controlled host. api.mainframe.co, docs.mainframe.co and developer.mainframe.co do
  not resolve (NXDOMAIN, checked 2026-08-13).
- www.mainframe.co is a three-page Webflow marketing site (`/`, `/contact-mainframe`,
  `/portfolio/crownribbon`), last published 2024-09-16.
- The GitHub organization github.com/MainframeHQ has 0 public repositories. Mainframe's public
  code lives in github.com/hifi-finance instead.
- The one machine-readable contract is the GraphQL schema of the Hifi Protocol subgraph.

## Developer surface

- [Hifi Protocol documentation](https://docs.hifi.finance/protocol/introduction): the protocol
  docs for Hifi, Mainframe's fixed-rate, fixed-term lending protocol. Footer reads
  "Copyright (c) 2025 Mainframe Group Inc."
- [Hifi SDK](https://docs.hifi.finance/protocol/developers/sdk): npm packages of Solidity
  contracts plus generated TypeChain/ethers.js bindings. A smart-contract SDK, not an HTTP client.
- [Hifi data access](https://docs.hifi.finance/protocol/developers/data): documents two paths —
  Multicall against the deployed contracts, and a GraphQL subgraph on The Graph.
- [Network addresses](https://docs.hifi.finance/protocol/developers/network-addresses): deployed
  contract addresses per network.

## GraphQL

- [Hifi subgraph schema](graphql/mainframe-hifi-subgraph-schema.graphql): the verbatim SDL, six
  `@entity` types — Position, Token, Hifi, Vault, Pool, Swap.
- [GraphQL manifest](graphql/mainframe-hifi-graphql.md): endpoint, provenance, and entity notes.
- Documented endpoint `https://thegraph.com/hosted-service/subgraph/hifi-finance/hifi` returned
